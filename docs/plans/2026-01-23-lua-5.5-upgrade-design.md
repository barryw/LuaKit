# LuaKit 1.4.0: Lua 5.5.0 Upgrade + swift-syntax Fix

**Date:** 2026-01-23
**Version:** 1.4.0+lua5.5.0

## Scope

This release combines two changes:

| Change | Type | Risk |
|--------|------|------|
| Update swift-syntax URL to `swiftlang/swift-syntax` | Dependency fix | Low |
| Upgrade embedded Lua from 5.4.8 to 5.5.0 | Major dependency update | Medium |
| Add `LuaState(libraries:)` API for selective library loading | New feature | Low |

## Lua 5.5.0 Features

Users gain access to:

- Global variable declarations (new language feature)
- Named vararg tables
- Read-only loop variables
- `table.create` function
- ~60% smaller arrays (internal optimization)
- Incremental major GC (internal optimization)

New C API exposed via Swift:
- `luaL_openselectedlibs` → `LuaState(libraries:)`

## New Swift API

### LuaLibrary OptionSet

```swift
public struct LuaLibrary: OptionSet {
    public let rawValue: Int

    public static let base      = LuaLibrary(rawValue: 1 << 0)
    public static let coroutine = LuaLibrary(rawValue: 1 << 1)
    public static let table     = LuaLibrary(rawValue: 1 << 2)
    public static let io        = LuaLibrary(rawValue: 1 << 3)
    public static let os        = LuaLibrary(rawValue: 1 << 4)
    public static let string    = LuaLibrary(rawValue: 1 << 5)
    public static let math      = LuaLibrary(rawValue: 1 << 6)
    public static let utf8      = LuaLibrary(rawValue: 1 << 7)
    public static let debug     = LuaLibrary(rawValue: 1 << 8)
    public static let package   = LuaLibrary(rawValue: 1 << 9)

    public static let all: LuaLibrary = [.base, .coroutine, .table, .io, .os, .string, .math, .utf8, .debug, .package]

    /// Safe subset: no file I/O, no OS access, no debug
    public static let sandboxed: LuaLibrary = [.base, .coroutine, .table, .string, .math, .utf8]
}
```

### New LuaState Initializer

```swift
public init(libraries: LuaLibrary = .all) throws
```

### Usage Examples

```swift
// Full access (current behavior)
let lua = try LuaState()

// Sandboxed - no io, os, debug, package
let sandbox = try LuaState(libraries: .sandboxed)

// Custom selection
let custom = try LuaState(libraries: [.base, .string, .math])
```

## Implementation Steps

1. **Fix swift-syntax URL**
   - Change `apple/swift-syntax` to `swiftlang/swift-syntax` in Package.swift

2. **Download and extract Lua 5.5.0**
   - URL: https://www.lua.org/ftp/lua-5.5.0.tar.gz
   - SHA256: `57ccc32bbbd005cab75bcc52544052535af691789dba2b9016d5c50640d68b3d`

3. **Replace Lua sources**
   - Replace all `.c` files in `Sources/Lua/`
   - Replace all `.h` files in `Sources/Lua/include/`
   - Preserve the custom `module.modulemap`

4. **Update platform defines**
   - Verify `LUA_USE_MACOSX` and `LUA_USE_IOS` still work in 5.5
   - Adjust if needed based on new `luaconf.h`

5. **Implement LuaLibrary and new initializer**
   - Add `LuaLibrary.swift` with OptionSet
   - Add new `init(libraries:)` to `LuaState.swift`
   - Use `luaL_openselectedlibs` under the hood

6. **Build and test**
   - `swift build --configuration release`
   - `swift test --configuration release --parallel`
   - Fix any compilation errors or test failures

7. **Add new tests**
   - Tests for selective library loading
   - Tests for sandboxed preset
   - Smoke tests for Lua 5.5 features

8. **Update documentation**
   - Update CLAUDE.md version references
   - Update README if it mentions Lua version
